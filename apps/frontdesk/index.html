Front Desk

An AI receptionist for a busy restaurant. It answers the phone, works out what the caller wants, checks the real table plan and books them in — so the staff can keep serving.

  • Books into the real systemIt uses the same table plan and rules as the restaurant's host stand, so it can never promise a table that isn't there.
  • Runs on this deviceNo server and no API key. Nothing you type or say to it leaves your browser.
  • Tested on every phrasingMeasured against a list of real-world things callers say, including ones it was never tuned on.

    How it works

    1. Hears

      Speech becomes text with Whisper, a speech-recognition model that runs on your own device. Or just type.

      AI model · on device
    2. Understands

      A reader built for this one job pulls out the party size, day, time, name, number and anything the kitchen needs to know. A small language model catches the phrasings it wasn't written for.

      Parser + AI fallback
    3. Checks the floor

      It asks the restaurant's own booking engine whether a table is free, and if not, finds the nearest times that are.

      Rules, fully tested
    4. Replies

      One question at a time, never for something already said. It reads everything back before booking, and hands over to a person when it should.

      Conversation logic
    5. Writes it in

      The booking goes into the table plan, the allergy goes to the kitchen, the confirmation text is drafted, and it checks the table is still free at the moment it writes.

      Live sync with Covers

      Taking it to a real restaurant

      The phone line next step

      A telephony provider streams the call audio to the same pipeline. The conversation logic doesn't change — it already takes text in and gives text out.

      Their booking system designed for

      The receptionist asks one question of the book — is there a table? — so connecting a different booking system is one adapter, not a rewrite.

      Knowing when to stop built

      Parties over ten, complaints, a name it can't find, three misunderstandings in a row: each one becomes a callback for the manager instead of a guess.

      Getting better every week built

      Every call it gets wrong becomes a new line in the test set. The score above is recomputed every time the page loads, and the tests fail if it ever goes down.
